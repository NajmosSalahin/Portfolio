# Portfolio Website —  ---  Build me a personal portfolio website in React. I'm a Data Scientist & Full-Stack Developer and I want a fast, fully responsive, single-page site — not something that looks like a generic template.  ## Tech stack - Vite + React 18, plain JavaScript (JSX, no TypeScript) - Tailwind CSS for styling - Framer Motion for animation - lucide-react for icons - Anchor-link / `react-scroll` smooth-scroll navigation (no router needed — it's one page) - No backend — the contact section links directly via `mailto:` / `tel:` and socials. Leave a clearly marked spot to wire up Formspree (or similar) later if I want a working form - Should be deployable as-is to Vercel, Netlify, or GitHub Pages  ## Design direction Ground the design in who this is actually for — a data/software person — not a generic "creative portfolio." Please avoid the three looks every AI-generated site defaults to right now: (1) cream background + terracotta accent + serif display, (2) near-black background + one neon accent, (3) broadsheet/newspaper hairline-rule layout. Only use one of those if you have a real reason to for this brief.  - Pick a real, named palette (4–6 hex values) and deliberately pair a display face with a body face, plus a monospace face used sparingly for nav labels, tags, and tech-stack pills — that fits a developer's site naturally. - Give the page one signature moment that reflects "builder who works with data" — e.g. a small animated chart/plot in the hero, a terminal line that types itself out, a subtle scatterplot/grid texture. Execute that one idea well and keep everything else quiet and disciplined. - Education and experience are genuinely chronological, so a timeline treatment is earned there. - Motion should be orchestrated, not scattered: a considered load-in sequence, scroll-triggered reveals per section, tasteful hover states on project cards. Respect `prefers-reduced-motion`. - Full light/dark mode toggle. Responsive from a 360px phone up to a 4K desktop. Visible keyboard focus states. Semantic HTML throughout.  ## Site structure (single page, sticky nav, smooth scroll) 1. **Navbar** — sticky; name/initials as logo; links to each section below; mobile hamburger menu; light/dark toggle 2. **Hero** — name, title, tagline, CTA buttons ("View Projects", "Get in Touch", "Download Resume"), social icons (GitHub, LinkedIn, email) 3. **About** — short bio, plus a few quick facts (currently studying, based in, languages) 4. **Education** — timeline or cards, most recent first 5. **Experience** — timeline or cards 6. **Skills** — grouped by category as tag/pill clusters 7. **Projects** — responsive card grid; each card shows name, description, tech tags, and links to GitHub/live demo where I have them 8. **Certifications** — card or list, each linking out to the certificate file where I have one 9. **Contact** — email, phone, socials 10. **Footer** — copyright + repeated social links  ## Content — use this exactly.
