# Portfolio — Md. Najmos Salahin

Personal portfolio website built with **Vite + React 18**, **Tailwind CSS**, **Framer Motion**, and **lucide-react**.

## Quick Start

```bash
npm install
npm run dev
```

## Build for Production

```bash
npm run build
npm run preview
```

## Deploy

The output is a static `dist/` folder. Deploy to **Vercel**, **Netlify**, or **GitHub Pages** with zero config — just point it at the repo root.

## Project Structure

```
src/
├── data/portfolio.js        # All content data
├── components/              # One component per section
├── assets/profile.jpg       # Profile photo (optional)
├── App.jsx                  # Root composition
├── main.jsx                 # Entry point
└── index.css                # Tailwind + fonts
public/resume.pdf            # Resume download
```
